Values are FY2025, the latest full fiscal year; change is since the first year with a value, usually FY2016 (percentage points for shares). FY2026 is preliminary (NIH is still adding records) and is dashed. Institute values exist for KPIs computed by administering institute; the others show all NIH. Counts cover the full NIH portfolio, not a sample, so there are no sampling intervals; label agreement with hand coding is κ = 0.92 for AI and 0.86 for data science.
DS = data science. AI = artificial intelligence. FY = federal fiscal year. RCDC = Research, Condition, and Disease Categorization. RCR = Relative Citation Ratio. HPC = high-performance computing. FAIR = findable, accessible, interoperable, reusable. IDeA = Institutional Development Award states. K = career development award. LLM = large language model. A record = one project or center component, counted in each year it was funded; funding = extramural attributed cost, center costs counted once.
Sources: NIH RePORTER and ExPORTER (projects, publication, patent, and clinical study links), iCite, NIH Data Science Taxonomy v0.5 labels. Laura Ellis.
